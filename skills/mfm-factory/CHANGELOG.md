# Changelog

## 1.1.1 — 2026-09-15

Make hosted specification authoring self-contained. Bundle the spec reference and
clarify hosted authority even in local Docker. Shared format code now belongs to
the neutral Python package; generated resources remain standalone. This cleanup
does not deliver new construction runtime capabilities.

## 1.0.0 — 2026-09-14

Initial alpha: one MCP-based workflow for named variants, a single logical model,
explicit architecture graphs, executable mock products and construction feedback.
Includes MFM Data Model 1 and MFM Architecture 1 starting formats. Documents the
current hosted Factory capability gap; excluded from public distribution pending
end-to-end tool support.
